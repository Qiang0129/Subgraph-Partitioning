## 本轮 Windows OCR 修复

此前 `vision.py` 尚未包含修复。旧初始化曾在中文缓存路径下加载模型失败；切换为 ASCII 路径后，又在 oneDNN 推理指令处报 `NotImplementedError`。本轮将以下处理写入实际代码：

- 在首次导入 PaddleOCR / PaddleX 之前配置缓存。Windows 默认使用 `%LOCALAPPDATA%\SubgraphPartitioning\models`；`SFA_OCR_CACHE` 优先，其次保留已有 `PADDLE_PDX_CACHE_HOME`。中文用户路径尝试系统短路径，仍非 ASCII 时明确报错并提示配置。
- 显式设置 `device="cpu"`、`cpu_threads=4`、`enable_mkldnn=False`。
- 用 Pillow 解码中文图片路径、规范化 EXIF，并将连续 BGR 数组传给 PaddleOCR。
- 保留 OCR 不可用的失败状态，同时将异常堆栈写入本地服务日志。

实测环境：Windows、Python 3.12.4、PaddleOCR 3.7.0、PaddlePaddle 3.3.1、PaddleX 3.7.2、NumPy 2.3.5、OpenCV contrib 4.10.0.84、Java 21.0.8、Maven 3.9.12、Node 22.17.0。`pip check` 通过。
